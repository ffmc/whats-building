Do's and Don'ts

Do
  • Bind every value to a token — no hardcoded hex/px.
  • Reserve IBM Plex Mono strictly for numerals/tabular data.
  • Keep large surfaces sharp; keep pill shapes rare (lens bar, toggle only).
  • Let whitespace separate before reaching for a border or shadow.
  • Use dataAI/dataBaseline as the only meaning-carrying color pair.
Don't
  • Don't add a third font, shadow tier, or accent hue without flagging it.
  • Don't default to rounded cards / soft shadows / indigo-violet — generic SaaS look.
  • Don't use gradients, frosted glass, or glow effects anywhere.
  • Don't add decorative color or chart-junk to explain a chart.
  • Don't reproduce Beagle-style playfulness — explicitly ruled out for this project.
